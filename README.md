# Task Yönetimi Projesi

Bu proje, React, TailwindCSS ve date-fns kullanılarak geliştirilmiş bir **görev yönetim uygulamasıdır**. Task bileşenleri, görev detaylarını gösterir ve teslim tarihine göre renk değişimi yapar.

## Özellikler

- React tabanlı modern frontend
- TailwindCSS ile responsive ve temiz tasarım
- date-fns ile tarih ve kalan gün hesaplamaları
- Görev tamamlanma butonu
- Dinamik renkler:
  - **Normal görevler**: `bg-normal` (mavi ton)
  - **Acil görevler**: `bg-urgent` (kırmızı ton)
